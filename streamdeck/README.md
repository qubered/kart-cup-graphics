# Kart Cup Stream Deck plugin

Three actions that drive the control server over HTTP (`GET /api/presets`, `POST /api/command`):

| Action | What it does |
|---|---|
| **Recall Preset** | Restores a saved preset (every output's layers + which outputs are armed). Optionally cut/auto it to air. The key shows the preset name and lights up while it is the current cue. |
| **Next / Previous Cue** | Steps through the cue stack (the preset list order in the control UI's Presets tab), optionally taking it to air. |
| **Take** | Cut or Auto the armed outputs. |

## Install (dev)

```sh
cd streamdeck
npm install
npm run build
# Stream Deck 6.9+ (macOS/Windows), Node 20 is bundled by Stream Deck:
npx @elgato/cli link com.qubered.kartcup.sdPlugin
```

Then drag the actions from the **Kart Cup Graphics** category onto keys. In any action's inspector set **Server** to the control machine, e.g. `http://192.168.1.20:8080` (shared by all actions; default `http://localhost:8080`).

`sdpi-components.js` is vendored in `ui/` so the inspectors work on an offline LAN. Icons are generated by `node streamdeck/make-icons.mjs` (uses the root `sharp`).

The API has no authentication, same as the control websocket: keep it on the show LAN.
